   │                                                             │
   │ • 仓库名建议:                                                │
   │   ✗ 避免: email, mail（太普通，可能被占用）                  │
   │   ✓ 推荐: corp-mail-legacy, internal-mail-2019             │

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【2.2 制作登录页面 (index.html)】

   操作步骤:
   ├── ① 在仓库中点击 "Add file" → "Create new file"
   ├── ② 文件名: index.html
   ├── ③ 粘贴登录页代码（见下方模板）
   └── ④ 点击 "Commit new file"

   代码模板:
   ┌─────────────────────────────────────────────────────────────┐
   │ <!DOCTYPE html>                                             │
   │ <html>                                                      │
   │ <head>                                                      │
   │   <meta charset="UTF-8">                                    │
   │   <meta name="viewport"                                     │
   │         content="width=device-width, initial-scale=1.0">   │
   │   <title>CORPMAIL - Login</title>                          │
   │   <link rel="stylesheet" href="style.css">                 │
   │ </head>                                                     │
   │ <body class="crt">                                          │
   │   <div class="login-box">                                   │
   │     <h1>CORPMAIL™</h1>                                      │
   │     <p class="subtitle">Internal System v2.3.1</p>         │
   │     <input type="text" id="username"                        │
   │            placeholder="用户名">                             │
   │     <input type="password" id="password"                    │
   │            placeholder="密码">                               │
   │     <button onclick="login()">登 录</button>                │
   │     <p id="error"></p>                                      │
   │   </div>                                                    │
   │   <script src="script.js"></script>                        │
   │ </body>                                                     │
   │ </html>                                                     │
   └─────────────────────────────────────────────────────────────┘

   ⚠️ 易错点:
   ┌─────────────────────────────────────────────────────────────┐
   │ • viewport meta标签必须加，否则手机显示会很小                 │
   │                                                             │
   │ • charset="UTF-8" 必须加，否则中文乱码                       │
   │                                                             │
   │ • 文件引用路径:                                              │
   │   ✗ 错误: href="/style.css" （多了斜杠）                    │
   │   ✓ 正确: href="style.css"                                  │
   │                                                             │
   │ • button的onclick函数名要和script.js中一致                   │
   └─────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【2.3 制作登录验证 (script.js)】

   操作步骤:
   ├── ① 创建新文件: script.js
   └── ② 粘贴以下代码

   代码模板:
   ┌─────────────────────────────────────────────────────────────┐
   │ function login() {                                          │
   │   const user = document.getElementById('username').value;   │
   │   const pass = document.getElementById('password').value;   │
   │                                                             │
   │   // ★ 在这里修改正确的用户名和密码                          │
   │   if (user === 'user_4712' &&                              │
   │       pass === 'butterfly2019') {                          │
   │     sessionStorage.setItem('auth', 'true');                │
   │     window.location.href = 'inbox.html';                   │
   │   } else {                                                  │
   │     document.getElementById('error').textContent =          │
   │       'ACCESS DENIED';                                      │
   │     document.body.classList.add('shake');                  │
   │     setTimeout(() => {                                      │
   │       document.body.classList.remove('shake');             │
   │     }, 500);                                                │
   │   }                                                         │
   │ }                                                           │
   └─────────────────────────────────────────────────────────────┘

   ⚠️ 易错点:
   ┌─────────────────────────────────────────────────────────────┐
   │ • 密码区分大小写！butterfly2019 ≠ Butterfly2019             │
   │                                                             │
   │ • 字符串要用引号包裹:                                        │
   │   ✗ 错误: if (user === user_4712)                          │
   │   ✓ 正确: if (user === 'user_4712')                        │
   │                                                             │
   │ • 跳转页面名称要完全匹配:                                    │
   │   ✗ 错误: 'Inbox.html' 或 'inbox.HTML'                     │
   │   ✓ 正确: 'inbox.html'                                      │
   │                                                             │
   │ • sessionStorage 在关闭浏览器后会清除（这是我们想要的）       │
   └─────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【2.4 制作收件箱页面 (inbox.html)】

   操作步骤:
   ├── ① 创建新文件: inbox.html
   ├── ② 添加页面保护代码（防止直接访问）
   └── ③ 制作邮件列表界面

   页面保护代码（放在<body>开头）:
   ┌─────────────────────────────────────────────────────────────┐
   │ <script>                                                    │
   │   if (sessionStorage.getItem('auth') !== 'true') {         │
   │     window.location.href = 'index.html';                   │
   │   }                                                         │
   │ </script>                                                   │
   └─────────────────────────────────────────────────────────────┘

   ⚠️ 易错点:
   ┌─────────────────────────────────────────────────────────────┐
   │ • 保护代码必须放在 <body> 最开头，不然页面会闪一下            │
   │                                                             │
   │ • 玩家可以通过开发者工具绕过，但普通玩家不会这么做            │
   │   如果担心，可以把真正内容也放在JS中动态加载                  │
   │                                                             │
   │ • 每封邮件单独一个页面（mail1.html, mail2.html...）          │
   │   比全写在一个页面更容易维护                                  │
   └─────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   │                                                             │
   │ input, button {                                             │
   │   display: block;                                           │

   │                                                             │

   │   25% { transform: translateX(-5px); }                     │
   │   75% { transform: translateX(5px); }                      │
   │ }                                                           │
   │ .shake { animation: shake 0.1s linear 3; }                  │
   └─────────────────────────────────────────────────────────────┘

   ⚠️ 易错点:
   ┌─────────────────────────────────────────────────────────────┐
   │ • CSS颜色值必须带 # 号: #00ff00 不是 00ff00                 │
   │                                                             │
   │ • 分号不能漏！每行属性结尾都要有 ;                           │
   │                                                             │
   │ • 手机适配: 确保 input 的 font-size >= 16px                 │
   │   否则iOS会自动放大输入框                                    │
